# Web Report Print Preview

The report design is generated by the existing file:

```text
lib/features/reports/pdf/dynamic_report_pdf_builder.dart
```

That file is intentionally unchanged.

On Flutter Web, **Print / Save PDF** uses the `printing` package platform print API. The active browser opens its normal print preview. In Chrome and Edge, select **Save as PDF** under Destination to download the generated report.

The browser print dialog controls printer selection, paper destination, copies, scale, and other browser-supported settings. The generated PDF content and design are not rebuilt from HTML and are not redesigned for printing.

Non-web platforms continue to open the existing Flutter PDF preview screen.
